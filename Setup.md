# 8086 Vending Machine Simulator — Development Setup

## 1. Project Environment

The project is being developed using 8086 Assembly Language with a lightweight development environment on Windows.

- **Operating System:** Windows
- **Code Editor:** Visual Studio Code (VS Code)
- **Build Tools:** Visual Studio Build Tools 2022
- **Assembler:** JWasm v2.11
- **Emulator:** DOSBox
- **Project Directory:** `D:\8086VendingMachine`

Used to create, edit, and manage assembly source files.

Installed with the **Desktop development with C++** workload. The installation includes Microsoft's modern MASM assembler (`ml.exe`) and linker (`link.exe`). These tools were located but are not used in the verified DOS test workflow.

### JWasm
JWasm v2.11 is installed and working. It is a MASM-compatible assembler that supports 8086 instructions and DOS MZ executable output.

**Executable path:**
`D:\8086VendingMachine\tools\JWasm\JWasm.exe`

JWasm is used to assemble the source code and generate the test executable.

### DOSBox
Used to execute and test DOS programs in an emulated DOS environment.

## 4. Assembling the Source Code

Open the project folder in VS Code and create a terminal using **Terminal → New Terminal**.

Change to the project directory:

```powershell
cd D:\8086VendingMachine
```

### Generate an object file

```powershell
& "D:\8086VendingMachine\tools\JWasm\JWasm.exe" -0 -Fo test.obj test.asm
```

The `-0` option selects the 8086 CPU target.

The `-Fo` option specifies the output object filename.

### Generate a DOS executable

```powershell
& "D:\8086VendingMachine\tools\JWasm\JWasm.exe" -0 -mz -Fo test.exe test.asm
```

The `-mz` option selects DOS MZ executable output.

The command successfully generated `test.exe` for the basic test program.

## 5. Running the Program in DOSBox

Launch DOSBox and enter the following commands:

```text
mount d D:\8086VendingMachine
d:
dir
test.exe
```

Explanation:

- `mount d D:\8086VendingMachine` mounts the Windows project directory as drive D: inside DOSBox.
- `d:` switches to the mounted drive.
- `dir` lists the files available in the directory.
- `test.exe` executes the test program.

### Verification Result

The test program executed successfully in DOSBox and displayed:

```text
Hello from 8086 Assembly!
```

This confirms that the basic source-to-executable-to-DOSBox workflow works for the test program.

## 6. VS Code Extensions

No VS Code extension is required to run the JWasm commands above; the assembler is invoked directly from the terminal.

If assembly-language editing assistance is desired, the previously identified option is **Basic Support for MASM/TASM**, published by `xsro`. Install it only if needed and available in the Marketplace. Its installation has not been verified as part of the working test.

Avoid installing multiple overlapping assembly-language extensions.
